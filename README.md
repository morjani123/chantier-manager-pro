# Chantier Manager Pro

Interactive BTP management portfolio demo built with React, TypeScript and Vite. No backend required. Demo data is stored in your browser via localStorage.

## Run

```bash
npm install
npm run dev
```

Build: `npm run build`.

Modules: Dashboard, Chantiers, Stock, Bons, Personnel, Engins, Fournisseurs, Finances and Paramètres. Demo data only: do not use for real company operations without a secure backend, authentication and access controls.
